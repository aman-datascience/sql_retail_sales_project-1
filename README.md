# SQL Retail Sales Analysis

## Project Overview

This project focuses on analyzing retail sales data using SQL to uncover meaningful business insights from transactional data.

The project covers the complete SQL analysis process, starting from creating and cleaning the dataset, followed by data exploration and solving real-world business problems using SQL queries.

The main objective of this project is to demonstrate practical SQL skills and the ability to use SQL for data-driven business analysis.

## Dataset

The project uses a retail sales dataset containing transactional information.

### Main Columns

| Column | Description |
|---|---|
| `transactions_id` | Unique transaction ID |
| `sale_date` | Date of the sale |
| `sale_time` | Time of the sale |
| `customer_id` | Unique customer ID |
| `gender` | Gender of the customer |
| `age` | Age of the customer |
| `category` | Product category |
| `quantiy` | Quantity of products sold |
| `price_per_unit` | Price per unit |
| `cogs` | Cost of goods sold |
| `total_sale` | Total value of the sale |
